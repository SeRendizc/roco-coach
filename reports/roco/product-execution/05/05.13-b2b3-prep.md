```jsonc
"affinity": {
  "source": "src/client/type-affinity.data.js@roco-world-s4-2026-09-10", // 生成产物 + 规则集 id
  "vs_types": ["水系"],                       // 对手**场上**那一只的属性（公开面）
  "rows": [                                   // 我方：在场那只 + 合法换人候选，最多 6 条
    { "pet_id": "pet_000001", "multiplier": 0.5, "known": true },
    { "pet_id": "pet_000417", "multiplier": 1,   "known": true }
  ],
  "unavailable": [                            // known:false 的**必须**在这里逐条出现
    { "pet_id": "pet_000190", "reason": "防御组合没登记：这一只的属性组合在相性表里查不到" }
  ]
}
```

| 值 | 来源 | 公开性 |
|---|---|---|
| `multiplier` | 页面用 `incomingAffinity()` 从**生成产物** `type-affinity.data.js` 现算（与 `roco.js:2319`/`:2490` 渲染用的是同一次调用） | **公开**：只吃我方属性 + 对手**场上**属性（`view.opponent.field.types`） |
| `vs_types` | `view.opponent.field.types` | 公开（对手场上那一只的属性是亮着的） |
| `known` | `incomingAffinity()` 的 `known` | —— |
| `source` | 生成产物文件名 + `RULESET_ID`（H4 之后页面里那个 id 的唯一来源） | 公开 |

**仍读不到（不许上传、不许补）**：对手**后备**的属性与身份（除非 `seen_roster`/`revealed_skills` 已亮明）、
对手这一手要出什么、技能面板（atk/def/speed）、进攻向倍率（那是引擎 `damage_preview.samples[].multiplier`，
与本字段**两件事**，`type-affinity.js` 文件头明令不许混）。
