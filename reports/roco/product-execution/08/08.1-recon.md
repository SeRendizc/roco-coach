## 5 · 实现顺序草案（小步可冻结 + 每步判据 + 两向变异）

> 原则：**先键、后尺子、再接偏好、最后跨页**。每一步都能单独冻结；每步都写「正例 + 反例（把正确的改坏必须红）」。

**S1（先做，最小）· 配招记录加个体维度**（对 G01）
- 改：`src/client/loadout-store.js`（键从 `pet_id` → `instance_id`，或引入 `instance_id` 维度并保留物种键做兼容读取）+ `team-workshop.js` 写入点 + `box-loadout.js` 读写点。
- 判据：① 同种两只个体，A 改配招**不影响** B（新判据）；② 老记录（只有物种键）读得到、不炸（兼容）；③ `battle/new` 的 `loadouts` 仍按引擎要的 `pet_id` 组装（**引擎口径不变**）。
- 两向变异：把键改回 `pet_id` ⇒ ①必红；把兼容读删掉 ⇒ ②必红。
- 冻结面：只碰这 3 个 client 文件 + 1~2 个判据文件。

**S2 · 培养比较加阈值口径**（对 G02/C1–C3/C6）
- 改：`src/coach/nature-advice.js`（新增「先手线/承伤/伤害」三个阈值函数，复用 `panelOf` 同一投影）+ `runtime.js:491` 的调用点。
- 判据：① 同一只、两种性格 ⇒ 先手档位/承伤档位**至少一项**变化，且每个数都能追到面板；② **缺天分时按 U4 的口径**（缺的一半不算 + 正文说清）；③ 量纲说明必须出现在输出里（沿用 `RELATIVE_UNIT` 的做法）。
- 两向变异：把阈值换成"直接比较面板数字" ⇒ ①的档位断言必红；让缺失的一半按 0 算 ⇒ ②必红。

**S3 · 「一个必要调整」补前后对照**（对 G03/C5/R2）
- 改：`src/coach/team-compare.mjs`（在 `minimalReplacement` 旁边加 `beforeAfter()`：同一组轴、同一份输入，两栏 + delta + 量纲 + `confidence`）。
- 判据：① 前后两栏的轴集合一致、delta 可手算核对；② unknown 分布时**不许**出现任何「更优/更好」字样（`BANNED_CLAIM_WORDS`）；③ `replacement:null` 时仍然给「不调整」那一栏（U5）。
- 两向变异：把 delta 写成百分数 ⇒ ②必红；把 unknown 分支改成给数字 ⇒ ②必红。

**S4 · 偏好接线（goal → 培养 priority）**（对 G05/U3）
- 改：`src/coach/runtime.js`（把 `memory.goal` 映射成 `priority`）+ 必要的判据。
- 判据：① `goal='稳健'` 与 `'速攻'` 下同一只的建议排序**不同**，且文案与排序一致（不能只说不动）；② `goal=null` 时落回既有默认（不许猜）。
- 两向变异：把映射删掉 ⇒ ①必红；`goal=null` 时硬塞一个默认目标 ⇒ ②必红。

**S5 · 08.5 跨页入口 + 对账**（对 G06/R8）
- 改：复盘卡加两个入口（去练习 / 去比一比这只的培养方向）+ 回来后的 `improved` 对账展示。
- 判据：① 从复盘点到练习页，`matchId`/`goal` 带得过去；② 对账卡分三态（改善 / 没改善 / **这次没法比**）；③ 不点入口时**不许**出现「已改善」。
- 两向变异：把 null 显示成「没改善」⇒ ②必红；链路断掉（入口不传 matchId）⇒ ①必红。

**依赖**：S1 与 S2/S3 文件不重叠，可并行；S4 依赖 S2（要先有 priority 才谈接线）；S5 依赖 S3+S4（对账要引用那次调整）。
