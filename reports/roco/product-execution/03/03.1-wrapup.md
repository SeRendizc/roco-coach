## 2 · 最小改钉留档（原断言**逐字**保留在此）

> 纪律：判据改动只在确证陈旧时；原断言逐字留档 + 独立运行时红因 + 最小修订。两处都由 Lead 的 R4 裁决触发（禁止仅凭我方速度层次把候选压 0）。

### 2.1 `tests/roco-opponent-belief.test.js` 判据④（权重分组）

**原断言逐字**：

```js
  // 独立复算：权重 = 层内 1/层大小，合计**恰好** 1（分数运算，不是浮点容差）
  const rows = belief.weights.rows;
  assert.equal(rows.length, belief.pool_size);
  const inStratum = rows.filter((row) => row.numerator === 1);
  assert.equal(inStratum.length, belief.stratum_size);
  for (const row of inStratum) assert.equal(row.denominator, belief.stratum_size);
```

**红因（独立运行时报据）**：改实现后 `weights.rows` 里的分数对是层内 `2/(2S+O)`、层外 `1/(2S+O)`（`exact()` 会约分，示例：`2/292 ⇒ 1/146`），于是「分子为 1」不再等价于「在选中层里」。
**修订**：改成按**权重值**分组（层内 = 最大值那组、层外 = 其余），断言 ①层内等权（一个分数对）②层外等权 ③层内 = 层外 × 2 ④**每行分子都 > 0**（R4 新增）。意图一条没松（层内等权 / 可复算 / 合计恰 1），并**加强**了「不许压 0」这一条。

### 2.2 `tests/roco-opponent-belief.test.js` 判据⑩（缺速度时的降级口径）

**原断言逐字**：

```js
  if (belief.available) {
    assert.equal(belief.pool_size, UNIVERSE, '⑩ 速度规则都不应用时池子不许被收窄');
  } else {
    // 缺速度 → 分层规则不应用 → 选中层为空 ⇒ 必须是「非空速度层」这条，而不是「筛空池子」
    assert.equal(belief.unknown_reason, FAIL_CLOSED_REASONS.REVEALED_EMPTY_STRATUM);
    assert.equal(belief.weights, null);
  }
```

**红因**：R4 之后「我方没有速度数据」不再 fail closed，而是**池内等权基线**（`uniform_over_pool_baseline`）；同时原断言把「速度规则不应用」误写成「池子不许被**任何**规则收窄」——池子被属性规则收窄到 461（< 622）本来就是对的。
**修订**：断言 available=true、`pool_size === 已应用规则的 output.after`、`stratum === null`、`weights.basis === 'uniform_over_pool_baseline'`、`is_probability === false`、**无 0 权重行**。意图保留并加强：不应用的规则不许偷偷收窄池子。

> `REVEALED_EMPTY_STRATUM` 常量**保留**：R4 之后它是**防御性不变量**（选层来自池子里真实存在的档 ⇒ 正常路径不可达），一旦触发说明选择逻辑坏了，fail closed 比全 0 权重诚实。该常量的说明文本已同步改写。
