## 1 · 候选生成路径（现状地图，逐段可复跑）

```
调用方注入 catalog（RC-303 buildCandidateIndex 产物）
        │
        ├─ buildCandidateUniverse(catalog)         ← 分母/成员：catalog.universeSpecies（实测 622）
        │     ├ featureFor(id).types / .spe        ← 冻结图鉴（公开物种事实）
        │     └ speedBandOf() → speedBandFor(index, spe)  ← RC-303 三分位（**工程分档**）
        │
调用方注入 publicFacts（手工拼）
        │
        ├─ readPublicFacts(publicFacts)            ← 白名单 + 隐藏字段出现即**拒绝整份**
        │
        └─ applyRules(universe, facts)             ← 3 条规则，逐条 append 账本
              ├ filter.revealed_types        对手已亮明系别 → 能接住的候选
              ├ filter.opponent_speed_tier   恰好单一速度档 → 同档候选（两端亮明/缺数据 ⇒ 不应用）
              └ weight.own_speed_tier_match  我方阵容最常见**且池子里存在**的档 → 该层等权
        │
        └─ revealedConditioned() → {pool, rule_ledger, weights(1/stratum_size 逐条), declared_semantics, unverified}

uniformBelief()   = 1/N 无信息基线（带声明）
frequencyBelief() = 恒 available:false（本仓无真实频次）→ 有来源的构造样例可亮（对照）
auditOpponentBelief() / beliefReport() = 判据与磁盘产物
```

**判据锚点（不能破）**：分母来自数据（`DENOMINATOR_NOT_FROM_DATA`）· 无信息必须声明 · 越界即拒绝 · 规则账本 `{reads, inputs, output, basis, applied}` · 权重精确分数且合计恰 1 · available:false 不许带任何数值 · 在线段不调引擎/子进程 · 伪精确零容忍 · 确定性逐字节。
