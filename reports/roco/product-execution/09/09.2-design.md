## 1 · S1 休息提醒的**可设口径**（G01；Q2 的语义）

**要做的四件**（全部落在 `profile.coach` + 本机记录，**不新增页面/路由**）：

| 项 | 语义（Lead 裁决） | 落点 |
|---|---|---|
| **延后** | **本会话内不再提**（不是「N 分钟」） | 会话级状态（`session.js` 的会话对象或 `profile.coach` 的 `restDeferSessionId`） |
| **时段** | 只在设定窗口内出（例如 22:00–08:00），窗口外**不出** | `profile.coach.restWindow = {from,to}`；读点在 `companion.js` 出句前判一次 |
| **时长上限** | 同一会话内最多说 N 次（默认 1） | 与 §2 的稳定 id 共用计数 |
| **关闭** | 沿用四档 mode 里的 `quiet`，并让 `restEnabled=false` 也能独立关 | `index.html:78` 的下拉 + 一个新 checkbox |

**要点**：判「窗口内」用**现实时间**（`dayPartAt(now)` 的同族函数），但**不许出现钟点数字**在玩家文案里
（`companion.test.js:1798` 的硬线：`不许报时`）⇒ 设置界面可以写 `22:00–08:00`，**小芽的话里**只许出现
「这么晚了」这类时段词。

**判据（正/反）**
- 正：窗口 `22:00–08:00` + 现在 23:30 ⇒ 出句；现在 15:30 ⇒ 不出（现有 `:1811-1813` 的白天反向已覆盖一半）；
- 正：延后 ⇒ **本会话内**再触发也不再出；**新会话**（重新开始一局或重开页面）⇒ 可以再出；
- 反：关闭后**任何**路径都不出（读点层、文案层、语音层三处都断）；
- 反：窗口外**即使**模型认为重要也不出（对齐 09 的必做反例②）。

**两向变异**：① 延后只写状态不参与判断 ⇒ 「延后后不再出」必红；② 把窗口判断放在**文案层之后**
（先出句再过滤）⇒ 「窗口外不出」必红；③ 关闭只挡主动侧、语音仍念 ⇒ 语音那条必红。

## 2 · S2 稳定 id + 跨局静默 + 两处渲染合一（G05 / R1 / R2）

**2a 稳定 id（Q2 的核心）**：把 `long-session:${run.count}` 改成**按会话起点分桶**的稳定 id：
`long-session:<sessionStartIso>`（会话起点 = 这一波里**最早那一局**的 ISO 时间；`SESSION_GAP` 不变）。
- 这样「同一波」= 同一个 id ⇒ `session.said` 与「点掉就不再说」**跨局成立**；
- 新的一波（间隔 > 90 分钟）⇒ 新 id ⇒ 可以再说一次（这就是「新会话可再次出现」）。
- 同一处口径也要覆盖 `late-night:${wave}:${n}`（`companion.js:983`）：改成 `late-night:<sessionStartIso>`。

**2b 跨局静默窗口**：`COMPANION_LIMITS`（`:2463`）是**单局**上限；新增跨局窗口
`REST_QUIET_WINDOW_MS`（建议 2 小时，落在 `memory.js` 的常量区，与 `ROLE_SILENCE_MS`/`DISMISS_WINDOW_MS`
并列，**不共用**这三个已有窗口 —— `memory-three-classes` 的判据 ⑤ 明确要求它们互不相等）。
记账写进记忆的**派生层**（`memory.reflections` 或新键，需 `purgeDerived` 能清），不进 RAG 输入。

**2c 两处渲染合一（R2）**：`app.js:117-151` 与 `box.js:1157-1189/1291-1296` 现在各取一次读点。
最小改法：把「取读点 + 判 hidden」抽成一个**共用函数**（放 `companion.js`，因为它已被两边 import），
两页只负责画。判据：同一时刻同一读点的可见落点数 ≤ 1。

**判据（正/反）**
- 正：同一波连打三局 ⇒ 「打久了」这条**只说一次**；点掉后**跨局不再出现**；
- 正：隔 100 分钟再开一局 ⇒ 新 id ⇒ 允许再说一次（**不是永久闭嘴**）；
- 反：把 id 改回 `long-session:${count}` ⇒ 「跨局不再出现」必红（**这就是 Lead 点名的两向变异**）；
- 反：两处渲染都打开 ⇒ 落点数 2 ⇒ 必红。
