\section*{一、开口六句}
\begin{enumerate}[leftmargin=1.4em,itemsep=1.2pt,topsep=1pt]
\item \x{规则引擎决定事实，模型只决定措辞。}（伤害/合法性/顺序/状态由引擎算；模型只理解、查证、组织语言）
\item \x{该不该调工具由代码定；调哪个、下一步看回执由模型定。}回执上限 3，首枪后最多再规划 2 次；\x{stopped 22 种}取值域有判据。
\item \x{回答里的数字/技能名/因果必须命中证据包}，否则整条降级成本地结论；但只保证“有出处”，不保证“语义对”。
\item \x{旧建议三层失效}：epoch 取消在途、交付前验 stateToken、客户端断连则服务端中止上游。
\item \x{检索我没赢}：四臂最好臂只 +2.68pp、不显著（p=0.45，CI 含 0）；保留关键词基线、公开负结论。

\end{enumerate}

\section*{三、五个追问的落点}
\begin{itemize}
\item \textbf{“多步/ReAct？”} 真 Agent 只有 \texttt{gatherAgentEvidenceOnce}；真实模型记录最大 1 次工具，多步只有确定性测试——不把代码能力冒充模型能力。
\item \textbf{“RAG 价值？”} 不是准确率，是带条件/反例/版本的可核查证据；没赢的实测 + 负例拒答 56.25\% 一起讲。
\item \textbf{“怎么防过期？”} \texttt{scheduler.js} epoch+abort、\texttt{app.js} stateToken/身份、服务端断连中止。
\item \textbf{“怎么证明学习？”} 只算无提示独立行动；阈值 3 次/2 局/合理率≥75\%；没有真人数据就直说没有。
\item \textbf{“你本人做了什么？”} 需求、交互、验收、AI 协作实现；不把 AI 代码说成手写；现场给变体就按“定位→找守卫→写反例→最小改→验证”走。
\end{itemize}
