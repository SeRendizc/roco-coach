## A. 为什么需要 LLM（引擎不是算得准吗）

- **30 秒结论**：引擎负责确定性部分（合法行动、伤害、顺序、状态计时），这部分交给模型只会更不可靠；
  模型负责接住自然语言、按需查证、把算好的事实组织成人话。**程序决定事实，模型只决定措辞。**
- **展开**：玩家说「我不想老换宠」「咋办」时，没有 LLM 只能写死所有说法，换问法就答不上；
  但让模型碰数值又会编。所以架构是「证据包 + 守卫」，模型只拿到已算好的证据。
- **证据**：`src/coach/runtime.js` 的 `localProvider` 与 `provider.generate(packet)` 分工；
  `checkGroundedAnswer`（数字/引用/因果/道具名/等级词）；`tests/evals/agent.test.js` 的
  `unsupported-number` / `unsupported-citation` / `item-name drift` / `causal-cancelled-action` 用例。
- **追问链**：①「那模型是不是可有可无？」→ 本地保底只能给短结论，接不住自由表述/追问；
  ②「你怎么证明模型那句更好？」→ **必须承认**没有独立措辞盲评；只有工具选择等结构化指标，且有改差的指标。
- **弱答信号**：说「模型能算伤害」「有了 LLM 建议质量就好了」。

## B. 哪里真的是 Agent

- **30 秒结论**：只有 `gatherAgentEvidenceOnce` 是有界工具循环；首步由政策强制发出，之后模型最多
  再规划 2 次、工具回执上限 3；停止原因是一个冻结取值域 `AGENT_STOPS`（**22 种**）。
- **展开**：下一步依赖上一步回执（`search_rules → compare_actions → read_state`）；
  预算耗尽/非法参数/重复调用/规划失败/正常停止都有出口；**不是**「固定流程调三个工具再润色」。
- **证据**：`runtime.js:4460` 循环、`:4505` 上限、`:2933` stops 取值；`tests/roco-agent-stops.test.js`
  双向钉（无未登记值/无死值）；`tests/coach.test.js` 的按回执换手用例。
- **追问链**：①「真实模型有多步吗？」→ **没有**：44+4 条记录 toolTrace 最大 1；多步只有确定性测试，
  不把代码能力冒充模型能力；②「那你怎么敢叫 Agent？」→ 有界循环 + 回执驱动 + 失败归因，但**承认**
  真实模型样本里没观察到多工具链，这是下一步要补的评测。
- **弱答信号**：「我们做了 ReAct 框架」但给不出一条真实工具轨迹（工具名+参数+为什么换下一个）。

## C. 工具合同与身份绑定

- **30 秒结论**：工具调用不是「函数随便调」——每个工具都有参数白名单、状态版本校验、
  回执形状校验；过期/错身份的请求会被拒绝，而不是静默返回。
- **展开**：`toolbox.js:144` 工具合同；`read_state` 等工具带 `state_version`，与当前状态不一致时拒绝；
  回执有 `chosenBy`（policy/model）与 `identityValidation`；客户端/服务端双层拦截隐藏信息。
- **证据**：`tests/evals/roco/plan-e2e.test.js`（隐藏信息发出前拦截 + 服务端 400 hidden_information）；
  `src/coach/game-adapter.js` 装配期 fail closed。
- **追问链**：①「工具返回旧状态怎么办？」→ 版本不一致直接拒，绝不拿旧回执回答新问题；
  ②「模型传错参数呢？」→ 参数 schema 校验 + `invalid-*` stopped + 一次纠错机会，仍错则降级。
- **弱答信号**：只说「用了 function calling」，说不出校验/失败语义。

## D. Grounded generation 的边界（今天最值得讲）

- **30 秒结论**：模型回答里的数字、技能名、道具名、因果、属性等级词必须命中证据包，
  否则整条降级成本地结论；但它是**窄守卫**，不是万能语义证明。
- **展开**：守卫能拦「999 伤害」「解药」「被取消的行动造成伤害」；**拦不住**「有依据但事实错」的
  语义错误——今天实测发现「电系打翠顶夫人是 2 倍」与证据 ×3 矛盾时旧守卫放行（因为 2/3 是规则常量、
  中文量词表没有「倍」）。修法：只在回执真的带洛克相性事实时，要求声称倍率能在证据里找到；
  「强力克制」=3×；「×4」判退役口径。
- **证据**：`runtime.js::checkGroundedAnswer`（scope 字段自述「not a proof」）；
  `tests/roco-scarlett-tier-grounding.test.js`（7/7，含「证据 ×2 时同一句 2 倍不许被拦」反证）。
- **追问链**：①「怎么保证语义正确？」→ 承认守卫只保证可追溯；语义正确要靠规则引擎/一手数据/
  独立评测，下一步做「等级词 × 相性表」的绑定校验；②「误伤怎么办？」→ 只在该回执有相性事实时判，
  自研小兽 1.5/0.75 规则常量不误伤（有对照测试）。
- **弱答信号**：说「我们做了 grounded，所以不会幻觉」。

## E. 信息边界与部分可观测

- **30 秒结论**：开局只公开对方六只；个体天分/性格/六维/四招/后备血量都隐藏。教练只能基于
  已观察事实、图鉴可能性、战斗证据推断——**知道物种 ≠ 知道对手配置**。
- **展开**：适配器契约里对手后备只允许 `{slot, fainted}` 两个键，多一个键整条拒收；
  客户端在请求发出前扫隐藏信息，Python 服务端再拦一次；有「反作弊对照」测试：
  只改隐藏天分/技能，教练收到的公开输入逐字段不变。
- **证据**：`game-adapter.js`；`roco-client.js` 隐藏键扫描；`service.py` 400 hidden_information；
  `tests/evals/roco/plan-e2e.test.js` 三份隐藏信息词汇表同源。
- **追问链**：①「模型猜对手下一步怎么办？」→ 只许说可能性/分支，确定性断言被守卫拦（B3 口径）；
  ②「怎么证明没偷看？」→ 反作弊对照 + 双层拦截 + 失败即拒。
- **弱答信号**：把「知道对方六只」说成「知道对方配招」。

## F. 过期建议与取消

- **30 秒结论**：旧建议三层失效——任务版本（epoch）取消在途请求、交付前再验 `stateToken` 与局面身份、
  客户端断连时服务端中止上游模型请求。
- **展开**：`scheduler.js`（20 行）单飞 + epoch + abort；`app.js` 交付前 `taskIsCurrent()`；
  `server/index.js` `res.once('close') → abort()`；慢模型 250ms + 40ms 时出招 ⇒ 交付列表为空。
- **证据**：`tests/evals/slow-model.test.js`（6 项）；`tests/server.test.js` 断连中止用例。
- **追问链**：①「晚到但玩家没出招呢？」→ 局面没变可交付，但只一次、不补发；
  ②「版本不匹配怎么办？」→ 知识检索/建议直接 blocked，不展示旧数值。
- **弱答信号**：「我们在 prompt 里让它注意时效」。

## G. 评测方法论（区分工程与学术）

- **30 秒结论**：先分清「原始模型输出 / 宿主替换后 / 最终页面」三种事实；失败/超时保留在分母；
  规则改动走「红→绿 + 改钉留痕 + 金标送审」；小样本只作描述性读数，不宣称统计显著。
- **展开**：四臂检索对照（128 条作者自写查询）用 McNemar 精确检验 + bootstrap CI；
  混合臂/反例臂相对关键词 +2.68pp、p=0.45、CI 含 0 ⇒ 公开「没赢」；负例拒答 56.25% 是更值得修的缺口。
- **证据**：`reports/retrieval-extended-summary.md`；`tests/evals/roco/agent-trajectories.test.js`
  （生成时判定 vs 现在重判）；`guard-selftest` 15/15。
- **追问链**：①「为什么不跑准确率？」→ 没有独立盲标集，自写查询不能当基准；先建盲测再谈准确率；
  ②「LLM-as-judge 可以吗？」→ 可以辅助，但不能单独决定正确性；规则类用程序判、解释类用 rubric+人工。
- **弱答信号**：只报一个通过率，说不清分母/失败算不算/样本多大。

## H. RAG 为什么「有效但没赢」

- **30 秒结论**：检索提供的价值是「带条件、反例、版本的可核查证据」，**不是**已证明的准确率提升；
  本仓四臂对照里最好的臂也不显著，所以保留关键词基线并公开失败。
- **展开**：外部游戏规则与本引擎不一致，直接搬会教错；知识卡本地写、带适用条件/反例/来源；
  实时伤害另外算，不拿经验句当数值证据；`rulesVersion` 不匹配直接不返回。
- **证据**：四臂数字 + 负例 56.25%；语义向量那轮纯语义 9/14 低于词项 11/14，只改善 MRR，未替换默认。
- **追问链**：①「那 RAG 的意义？」→ 可核查证据 + 版本可回查，不是准确率手段；
  ②「为什么不用向量？」→ 用了，实测没赢，保留失败结论。
- **弱答信号**：「加了 RAG 更准」。

## I. 记忆与学习（可证伪）

- **30 秒结论**：记忆分「事实 / 偏好 / 学习证据」三类；学习结论只写成**可修正假设**——
  只算无提示下的独立行动，3 次跨局才说「出现迁移迹象」，从不写「已掌握」。
- **展开**：`memory.js` 的 journal 区分 prompted；`adaptiveGate` / `transferAssessment` 阈值；
  `coachSelfAudit` 同时复盘小芽自己是否迟到/重复/出错；答对一道练习只记「答对过一道」。
- **证据**：`tests/evals/agent.test.js`「独立行动证据不足时不判断熟练」；`memory.js:230/472`。
- **追问链**：①「怎么证明学习？」→ 现在没有真人数据；能测的是提示下 vs 独立行为的分开记录，
  以及变式练习的迁移；②「胜率提高算学习吗？」→ 不算，胜率不是学习指标。
- **弱答信号**：「玩家用了之后胜率提高 X%」。

## J. 后训练边界（SFT / DPO / RL）

- **30 秒结论**：Agent 是执行系统，RL 是学习方法；本仓 RL 只做两个**窄**实验：
  表格 Q-learning 干预策略（何时开口，带打扰惩罚）、SmolLM2-135M 冻结骨干 + **1,152 参数**工具路由头
  （16 条留出 8→15），**不是**完整 Agentic RL，也没更新 DeepSeek。
- **展开**：奖励设计要防投机（刷提示、操纵采纳率、把玩家本来做对的归功 AI）；模拟收益 ≠ 真人收益；
  干预 5.89→1.70 只在 selectedSeed=71、且是模拟（三种子 1.70–2.32）。
- **追问链**：①「为什么只有 1152 参数？」→ 刻意缩到 CPU 可跑可复现的二选一任务，回答「链路能不能训」；
  ②「GRPO/PPO 会吗？」→ 讲清策略梯度、优势、KL、信用分配与采样成本，不把论文名当经验。
- **弱答信号**：「我们做了 RL 提升 Agent 能力」。

## K. 推理服务与延迟（模型服务岗会问）

- **30 秒结论**：先分清 prefill/decode、首 token 与总延迟；工程上可做确定性快路径（0 次模型调用）、
  答案缓存、本地/云端双路回退、token 预算与超时/取消；**今天只测了离线回退 p50 8.71ms**，
  真实模型延迟未重测（禁付费）。
- **展开**：`max_tokens`/证据包裁剪/token 审计；`cloudDecision` 决定哪些任务值得付费；
  8765 真实 DS 请求实测 1.52s（8 条证据）；官方斯嘉丽公开口径是 40s→2-10s、首字<2s（引用时说明是采访）。
- **追问链**：①「怎么降 p95？」→ 并行化、缓存命中、超时/降级、减少不必要思考轮数；
  ②「首 token 为什么重要？」→ 体感与可取消性；流式没做是短板，直说。
- **弱答信号**：把「40s→2s」说成自己的优化。

## L. 五个失败复盘（每个 90 秒）

1. **检索没赢**：概念扩展/语义检索没超过关键词基线（14 条里 10 vs 11）→ 保留基线、公开失败、下轮建盲测。
2. **planner 默认停止的权衡**：多余调用 75%→33.33%、自停 3.23%→96.77%，但漏调 0/19→7/19——不是纯改善。
3. **语音失败停用**：首次播报正常、之后粤语+爆音，触发 `speechSynthesis.cancel()` → 隐藏控件、保留代码、写明原因。
4. **测试假绿**：并行跑两套会互相改文件的验收 → 假红/假绿；单独重跑 1711/1711 全绿；此后这两类不许并行。
5. **规则真源三层不一致**（今天）：引擎/RAG 4× vs 客户端/游戏数据 3× → 用官方采访+上游实现+游戏数据三源推翻旧裁决，改钉留痕 + 金标重建。

## M. 如果进组：前 90 天做什么（对齐斯嘉丽团队）

- 第 9–12 周：独立 own 一个小模块（例如相性/等级词的语义守卫或教学子问题的评测），走完整
  「假设→红例→补丁→回归→送审」流程。
