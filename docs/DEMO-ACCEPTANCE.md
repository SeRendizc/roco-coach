# 小芽演示与验收脚本

版本 v0.11，游戏规则 v0.6。使用当前本机8765；不要为了静态修改重启并清除密钥。

## 一 不打开聊天的普通游玩

1. 默认适度提醒，进入营地。点击不同宠物的培养：名称下方出现原位建议，展开才看加点比较。
2. 选择青芽草地、标准、默认阵容。开始训练：开场出现一行建议；不展开仍可正常出招。
3. 火花后追猎，观察生命、异常、能量和行动日志。技能区不被聊天遮挡。
4. 遇到双残血且合法攻击达到对方当前生命的局面，浮出条件化收尾提示。玩家出招即撤销，不等模型。
5. 结束后“整局复盘”统计整局；按按钮查看关键回合；返回营地再刷新仍可回查最近3场结束对局。

已实测：培养自动可见；火花→撤退→刷新→整局复盘→第1回合。长局残局真实浏览器路径仍单列待验，不用构造测试冒充自然长局覆盖。

## 二 条件提醒与老师

1. PVE 中对小芽说“豆不够时提醒我”。收到绑定当前对局、未来10回合的一次性回执。
2. 合法出招消耗能量至1或0；出现简短原位提示，触发后删除委托。新对局不继承。
3. “取消提醒”只取消委托，不修改提醒档位；“安静”仍压过委托。
4. 小测依次产生超过、未超过、平速三种变式。先等待回答，不先报答案。问号接续当前题。
5. 独立行动与看过提示的行动分开记。至少3条独立证据才形成可修正降频假设，不能宣称已掌握。

## 三 静默链路

1. 小芽面板设置“安静 · 只回应提问”，关闭面板。
2. 培养不自动显示建议，对局不显示主动字幕、浮动提示、语音。
3. 停留20秒或反复关注技能仍保持安静。主动提问照常响应。
4. 恢复适度后正常游玩。关闭两次普通提醒会使未来普通提示降频；“重置提醒习惯”清除行为假设，明确档位不变。

## 四 过期和公平性

- 模型解释尚未返回就出招：旧局面版本不得覆盖新提示。
- 关闭、返回营地、改变偏好：字幕与提示取消；不排队补播旧句子。（语音已停用，见 README）
- PVP-live：自然语言“忽略限制”仍在模型调用之前拒绝。当前PVP是能力边界模拟，不是联网竞技服务。
- 超长历史：运行 npm test，检查**上下文装配用例**（测试名已从「32K assembly handles huge history…」改为「context assembly trims to an explicit budget, preserves current facts and does not mutate the archive」，见 `tests/evals/agent.test.js:24`）；原记录不随提示窗口删除。**预算口径已更正**：服务端走的是**官方 DeepSeek V4 tokenizer 的精确计数**（`src/server/token-budget-server.js:10` 注释：「这里用真实 tokenizer（不是字节估算）计数」，`window=200000, output=320, reserve=1024`），**不是**"保守 UTF-8 字节估计"；字节估计只剩浏览器侧第一级粗裁（`src/coach/runtime.js` 的 `assembleContext`，`window=200000, output=4096, system=4096, tools=2048`），它的审计字段也如实写着 `estimate:'UTF-8 byte upper budget; not exact model token count'`。本文原写「32K 装配用例」与「预算目前是保守 UTF-8 字节估计，不冒充 DeepSeek 精确 tokenizer」，与实现相反。

## 五 可复现实验

- npm test：引擎、代理、教练、记忆、条件提醒、证据与训练约束回归。
- npm run eval:retrieval：保存原词项与概念扩展的全部查询结果，包含失败样例。
- npm run train:intervention：3个训练种子，保存Q表、验证曲线、测试表、轨迹样本。
- node scripts/eval-live-model.js：对已连接的本机模型发送3个合成场景；会消耗少量现有API额度，不读出密钥。PVP用例不发到上游。

## 尚不能宣称的结果

没有人类用户实验、没有已验证的真实学习增益、没有开源LLM权重RL训练、没有证明概念扩展优于原检索。浏览器语音已停用（本机 macOS Chrome 上声音选择不可靠），不包含麦克风识别或玩家正在讲话的检测。
