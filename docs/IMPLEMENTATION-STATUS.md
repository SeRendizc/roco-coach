# v0.6 历史记录

## 本轮实际改变

1. **整局复盘**：由客户端本地归档读取整局，返回行动分布、3个关键回合和可点开的回合分析。原始记录保留当前对局与最近3场结束对局，刷新后可读。完整历史不直接塞进模型，只提供带回合ID的摘要。旧版未保存的历史无法补造。
2. **残局介入**：针对双方残血、存在合法攻击收尾条件，自动给短提示，说明伤害与防御/治疗风险。不是预测对方必然如何行动。安静模式不主动提示；关闭后本场不打扰；出招立即撤销。
3. **培养原位建议**：宠物名称下面自动显示建议，读当前培养预算和当前关卡首发面板，折叠展示加点前后速度与伤害比较。无需先打开聊天。
4. **入口修正**：战斗中的回合回顾读上一回合；结束后按钮变成整局复盘。聊天保留两个独立快捷入口。

## 验证与边界

- 全套73项测试通过。用户截图的残局参数测试得到潮汐重击38伤害、防御时13；不会声称必杀。

- 培养卡在浏览器自动显示。后续长局主动提示的完整浏览器验证仍记为未完成（C17）。
- 当前关键回合按减员/生命变化排序，不等于多步最优策略，也没有把一次胜负认定为掌握知识。

# v0.5 历史实现记录

本轮处理用户提供的失败对话与“没有停留提示、宠物没增加”的反馈。所有勾选表示代码和指定测试已完成，不代表真实模型质量已经验收。

## 本轮变化

### 对话与老师

- 首页“种子”改名为随机编号，加入悬浮说明；问种子时返回基于引擎的解释，禁止模型猜成培养资源。
- 最近8条会话、主题、未完成小测写入本机小芽记忆；刷新可恢复。清除记忆同时清除显示中的历史和待答题。
- 模型接收实际历史消息与当前任务状态；“为什么”“？”等追问沿用相关主题。
- 出题、判题、取消由程序控制，不经过自由生成。题目明确是模拟练习，判题给出实际算式。
- 答对只记为答对过一道练习，不再声称已经掌握。变式题和无提示迁移测试仍待实现。
- 培养说明包含当前关卡首发的速度比较，避免明明已更快却泛泛建议“再验证速度”。

### 主动提示

- 前台对战等待20秒，或8秒以上在不同可用动作间来回关注，产生候选提示。
- 每个决策最多一次，每局最多两次停留/关注提示，两次至少间隔45秒，显示10秒后收起。
- 不在后台、动画中、聊天中、预制体验、结束后或PVP触发。
- 适度 / 仅关键风险 / 安静三档。安静关闭主动提示；关键风险对停留提示采用濒危/补位门槛。
- 鼠标关注和键盘聚焦均记录动作；具体提示依据所关注的动作说明换宠、道具、防御、能量或灼烧的取舍。
- 关闭一条提示后本场抑制主动提醒；换局仍服从持久偏好。出招时隐藏旧提示。
- 当前是可测的规则门控，还没有训练用户习惯模型。hover不表示玩家水平低。

### 工具循环

`gatherAgentEvidence` 可调用 read_state、search_rules、compare_actions、inspect_training、read_last_turn。模型依据之前的工具回执选择下一步，最多两次工具调用；支持主动停止、非法工具/参数、重复调用、工具返回超预算和规划失败停止。只读，不替玩家操作。

DeepSeek 规划调用限时2.5秒，最终解释限时8秒；实时提示先使用本地分析，不等模型。工具轨迹附带工具名、参数和结果；不保存隐藏思考文本。

这是JSON工具协议的有界ReAct基础。用模拟规划器测试过不同工具序列、反馈依赖与拒绝非法工具；真实DeepSeek选择质量、证据引用校验、总token成本与多回合规划仍待验收。
