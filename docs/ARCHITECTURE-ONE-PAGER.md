## 1. 主链路（玩家不需要打开聊天）

```
游戏事件
  │  （回合开始 / 对手换宠 / 状态与能量变化 / 玩家查看某个动作 / 回合结算）
  ▼
宿主适配契约  src/coach/game-adapter.js
  │  宿主只给"可见状态 + 权限"，缺能力在**装配期**就拒（运行期不许降级）
  │  验证：tests/evals/roco/mock-host-integration.test.js（独立可重放宿主夹具，不依赖 DOM / 不需要 Chrome）
  ▼
快路径（确定性）  src/coach/policy.js
  │  合法性 / 明确机制 / 确定性数值 / 消息取消 / 简单风险 —— 这一档**0 次模型调用**
  ▼
要不要开口  src/coach/intervention-model.js  +  src/coach/experience.js
  │  评审重要性 / 置信度 / 是否仍可行动 / 新颖性 / 打扰量 ⇒ 沉默、延后、轻提示都是合法决策
  │  偏好（适度提醒 / 仅关键风险 / 关闭主动提醒）**先于模型与语音执行**
  ▼
有界 ReAct 与工具  src/coach/runtime.js（工具表）+ src/coach/toolbox.js
  │  首步由政策直调，之后**模型最多再规划 2 次**；工具回执上限 3
  │  工具：get_visible_state / search_rules / compare_actions / simulate_branches /
  │        read_player_memory / register_watch / cancel_watch / read_turn_evidence / create_practice
  ▼
证据与有效期校验  src/coach/runtime.js 的 checkGroundedAnswer
  │  模型输出里的**数字/技能名/行动**必须能在证据包里找到，否则整句丢弃 → 换本地结论
  │  局面版本会推进：迟到的模型结果**整条丢弃**并记原因（stale_result_discarded）
  ▼
展示或沉默   src/client/roco.html + src/coach/roco-experience.js
  │  固定边缘位置短句；不改变页面高度、不遮挡技能、不抢焦点、不强制暂停
  ▼
玩家行动 → 实际结果 → 记忆  src/coach/memory.js + src/coach/session.js
  │  区分"提示下做对"与"独立做对"；重要提示可登记成条件提醒（watch）
  ▼
复盘与培养  src/coach/teacher.js + src/coach/nature-advice.js
    整局复盘 → 关键回合；培养页原生给目标相关建议（本仓口径：**不给胜率、不给百分比**）
```

**一句话分工**：**引擎决定事实，模型只决定措辞。**
引擎（Python，`roco/`）算合法动作、伤害、顺序、状态计时；模型（`src/coach/runtime.js`）接自然语言、
按需查证、把算好的事实组织成人话。

## 2. 数据从哪来（四层，别混）

| 层 | 是什么 | 在哪 | 玩家能不能自己改 |
|---|---|---|---|
| **L1 图鉴** | 622 条：六维 / 属性 / 技能池 / 进化链（六维有 540 只采用抓包值） | `data/roco/normalized/roco-world-s4-2026-09-10/full-catalog.json` | 不能（事实层） |
| **L2 可模拟层** | **542 只**（2026-09-28 前是 48 只）：冻结配招（固有 ∪ 血脉 ∪ 技能石）+ 特性状态账本 | `.../layer-playable-48/` + `data/roco/engine-trait-status.json` | 不能 |
| **L3 个体层** | 玩家自己那几只：等级 / 资质 / 天分 / 性格（数据集里天分是种子化掷点，**不是**存档真值） | `src/coach/individuals.js` + `data/roco/owned/owned-pets.json` | 能（页面可加/删/比较） |
| **执行域** | 引擎内部那份六维与规则（**与 L1 有 5 只故意不同**：换"模拟逐比特可复现"） | `roco/src/roco_env/data.py` | 不能，且**不许改** |

> **L2 的 542 是怎么来的（2026-09-28 改钉，旧值不删）**：人类逐字拍板「就用现在抓包得到的数据吧，别的不找不要了，问题数据也不要了。**所有精灵实装**，这样就不需要我的精灵了，直接全筛选」⇒
> 可玩层从 48 只换成**纯抓包派生**的 **530 只**（旧的 36 只 overlay 退役），合并基线 12 只 = **542 只**；图鉴 622 条不变，另 **80 只**走按需推算档（原 574 只）。
> ⚠ **目录名仍叫 `layer-playable-48/`**（引擎 `roco/src/roco_env/data.py:22` 的 `LAYER_DIRNAME` 写死，没改）——那里的 **"48" 是名字，不是数量**。
> 旧 48 只里 **7 只**没进新层：**5 只**按人类拍板当问题数据剔除（古啦多 `pet_000139` / 学院呱呱 `pet_000485` / 祭礼巨像 `pet_000542` / 棋契陛下 `pet_000556`、`pet_000575` 两条同名形态），
> 另 **2 只**（新月鹭 `pet_000609` / 智辉章脑 `pet_000613`）**抓包里根本没有这两只**（id 落在 3761 起的空段），不在剔除决定里。
> 依据：`docs/roadmap/ALL-PETS-PLAYABLE-LAYER-2026-09-28.md`。

**那 5 只为什么不同**：`apply-capture-to-engine.mjs --check` 会报 20 条，这是**故意的**
（台账 §C6.325c 撤回了执行域采用）。**玩家看到的数读 L1 图鉴层**，引擎回执退为交叉核对，
判据 `tests/roco-hke-layer.test.js` ⑥ 把"只有这 5 只、且不许留采用痕迹"钉住。

## 3. 怎么证明它是对的（这是这个项目最该讲的部分）

| 层 | 手段 | 实测 |
|---|---|---|
| 单元 | `npm run test:unit`（**1714 条 / 157 个文件**） | 1714 / 1714 通过 |
| 门禁 | `npm run verify:release`（**27 套件**） | 见 `reports/roco/verification/latest.json` |
| 真实浏览器 | 真鼠标键盘跑：营地 / 战斗 / 盒子 / 工坊 / 换招 / 移动端两档（390×844、360×640） | 盒子 **36/36 + 反证 16/16**；工坊 **52/52 + 41/41**；战斗反馈 **10/10 + 15/15** |
| 真实引擎 | 起真 Python 服务跑端到端规划；桥的隐藏信息边界（对手待执行动作不许泄漏） | `plan-e2e` / `bridge` 套件 |
| **守卫本身会不会红** | `guard-selftest`：**往源码注入真实违规**，看守卫是否真的报错 | 登记 **15 条、红 15 条、仍绿 0** |
| 真机问句 | `probe-answer-speak.mjs`：对着跑着的服务逐句真问，再扫工程黑话 | **干净 20/20** |
| 数据溯源 | 每条来源有锚点（归档哈希 / 逐文件清单），孤儿引用为 0 | `provenance` / `game-data-pack` 套件 |

**两条纪律（面试里值得说）**：
1. **判据只许改钉不许删** —— 改一条期望必须带日期 + 人类原话 + 原因，旧值留在原地。
   例：面板那一档从"噼啪鸟 294"改成"492"时，294 **没有删**，它被移到 `stars: 0` 这一档继续钉着。
2. **数字只来自引擎/数据层** —— 玩家可见的结论不许出现胜率、概率、百分比；
   缺数据就写"未确认"。（守卫：`tests/roco-plain-speak.test.js` + `answer-quality` + 真机探针）

| "怎么证明玩家真的学会了？" | **证明不了**。现在只有规则层的"提示下做对 vs 独立做对"，**没有**心理测量模型、没有真人被试。这一条在设计文档里就标着"需真人被试"。 |
