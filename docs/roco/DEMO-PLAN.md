# 玩家可试玩 Demo：分阶段计划（P0 可玩 / P1 可展示 / P2 旗舰）

**优先级切换（用户指令）**：release gate 收尾后立刻切到「玩家可试玩的旗舰 Demo」，
**暂停继续扩模型 / 刷内部评测**。用户实测 `/roco.html` 反馈「非常差」，复核属实：
**这页目前是验收夹具，不是产品 Demo。**

模型与评测线**不删不废**，只是**排队**：它们的产物（v4 适配器、1,752 条候选轨迹、
介入判定层）在 P0 里以「开发者面板 / shadow 可观测」的形式出现，不进入玩家正文。

## 1. P0（可玩）——目标：**一个陌生人能打开页面、选队、打完一局、看懂每一句话**

| 子项 | 交付 | 验收（都要有可复现证据） | 估工 |
|---|---|---|---|
| P0-1 数据面分离 | Python `ui_public_view`（真名/系别/六维/能量/状态）+ envelope 并行字段；Node `publicView` 优先读 `result.ui`；`coach_planner_state` **零改动** | 新增守卫：`public_planner_state` 的字段集**不得**出现 `name`；`ui_public_view` 必须带真名；两条链的 `state_version` 一致 | 1 轮 |
| P0-2 事件中文化 | 事件 → 中文句子的**一处实现**（Python 侧给 `text`，JS 侧只兜底）；原始 JSON 进默认收起的「调试信息」 | 页面 DOM 里**搜不到** `"kind":"`、`{"`、`pet_000` 这类字串（写成断言） | 1 轮 |
| P0-3 战斗 Demo UI | 6—12 只可选（真实 12 只）、3v3、对手可选；卡片含真名/系别标签/六维/血条/能量/状态；技能面板含**真实技能名 + 描述 + 能耗 + 威力或"来源未给"**；头像用**自制色块 + 系别配色 + emoji 剪影**（**不抓官方图**） | 浏览器验收：至少 6 只可选、能开局、能打完一局；每张卡都有名字与系别；技能描述来自规范化数据而非硬编码 | 2—3 轮 |
| P0-4 开发者抽屉 | 玩家区只剩人话；工程话 + 验收钩子说明移入默认收起、需要显式打开的抽屉 | 默认折叠；`<details>` 之外不出现 `fail closed` / `data-roco` 字样 | 0.5 轮 |
| P0-5 shadow 对照面板 | 抽屉内：同一局面下规则臂选了什么工具、本地 Qwen 选了什么、是否一致；标注「模型只提议工具，事实与结论文本仍由规则与 planner 提供」 | 真跑一次本地网关（v4），面板出现两条选择记录；面板文案明确**不替代 planner** | 1 轮 |
| P0-6 诚实口径 | Demo 页与文档只用 **1,752 口径（92.29%，配对退化 42/扳回 0）**；`off` 保持默认 | 全局搜索不得出现用 `275/288` 描述"整体能力"的句子；设置项里 `on` 不可从 UI 打开 | 0.5 轮 |
| P0-7 产品验收 | `scripts/roco/demo-product-acceptance.mjs`：7 条产品判据 + 截图 + 每步 DOM 快照 | 一条命令跑完并出 `reports/roco/demo-product/*.png` + JSON 报告；反证：故意注入 ID 占位/裸 JSON，必须判红 | 1—1.5 轮 |

**P0 合计 ≈ 7—9 轮**（按当前节奏约 **1 天**连续工作；P0-3 是最大块，也是唯一可能超时的一块）。

**P0 完成的判据（一次看全）**：打开 `/roco.html` → 看到 3 只带真名与系别的精灵 →
能换队/换对手 → 开局 → 每回合有中文事件叙述 → 小芽短提示自动出现且可关掉 →
点「让小芽看一眼」能看到依据（含真实技能与数值来源）→ 局末有教学卡 →
抽屉里能看到本地模型对照与原始 JSON → 一局打完没有出现任何 ID 占位或裸 JSON。

## 2. P1（可展示）——目标：**能拿去给别人演示、录屏、投屏**

| 子项 | 内容 | 估工 |
|---|---|---|
| P1-1 形象体系 | 12 只精灵的统一视觉：系别配色 + emoji 剪影 + 状态图标；血条/能量条动画；伤害数字浮层 | 1—2 轮 |
| P1-2 教学流程 | 开局引导（30 秒内说清这是什么）、局末教学页（一个关键决策点 + 一条可执行改法）、可回看 | 1—1.5 轮 |
| P1-3 陪练人格 | 小芽的口吻统一（情绪回应 / 克制 / 不打扰）、记忆可见可纠正（偏好与长期记忆独立展示，不是对局摘要） | 1 轮 |
| P1-4 布局与可读性 | 移动端优先的布局、对比度、色盲友好的系别标识（不只靠颜色）、字号与触控目标 | 1 轮 |

**P1 合计 ≈ 5—7 轮**（约 **1—1.5 天**）。

## 4. 这一阶段不动的东西（防止为了 Demo 破坏已有纪律）

- **不为 UI 扩大模型协议**：`public_planner_state` 保持最小；UI 用并行视图。
- **不抓官方图**：素材许可不明时用自制色块/剪影/emoji。
- **不据单世界数字声称能力**：一律 1,752 口径 + 配对差异。
- **不打开 `on`**：模型在 Demo 里是「可观测的对照项」，不是决策者。
- **不删旧测试**、不把验收脚本改成只测接线。
- 模型/评测线**暂停但不回滚**：产物与预注册文档原位保留。
