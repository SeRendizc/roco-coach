### ⚠ 推翻旧交接的一条结论：「8765 跑的是旧代码」**对静态资源不成立**

旧交接 §3 说「8765 自 09-28 起没重启 ⇒ 仓库修好的前端没生效」。实测**逐字节比对**：

```
$ for f in roco.html roco.js xiaoya.js roco.css battle-v3.css type-affinity.js type-affinity.data.js box.js; do
    curl -s "http://127.0.0.1:8765/src/client/$f" | diff - "src/client/$f" && echo "$f IDENTICAL"
  done
→ 8/8 全部 IDENTICAL（diff 0 行）
```

⇒ **`src/**` 是每次请求读盘的静态文件**，工作区一落盘就在用户那一页生效。
`started_at` 不变**不代表**前端是旧的。这条对全队都重要：**改 `src/**` 等于直接上线**，
改错了也一样（本轮真的发生过一次，见 §4）。

**每个读数都带一个自证**：`scripts/roco/lead-product-acceptance.mjs` 每次跑都重新做一次上面的比对，
把结果写进读数（`workspaceHeads[].servedEqualsDisk`），所以「屏幕上是哪一版」不靠推断。
