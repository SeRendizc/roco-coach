## 2. 口径登记：冒号的语义（**Lead 已裁决 ✓**）

```
「获得萌化**：**<效果>」的两种读法：
  ① **顺带（并列）**：获得萌化 **且** 同时执行 `<效果>` ✓  ← **Lead 2026-09-30 裁决取此** ✓
  ② **触发**：`<效果>` 是萌化带来的（只有萌化生效才发生）
裁决理由（三条 ✓）：① 人类授权「所有不冲突规则都列为引擎有效规则」⇒ 并列 = 无条件执行 = 冲突最小 ✓
  ② `285`「敌方获得1层萌化」**没有冒号** ⇒ 带冒号的那些是"顺带" ✓（**与无冒号的形成对照** ✓）
  ③ 这是**本地规则拍的口径** ⇒ **必须登记 `ENGINE_HYPOTHESIS` 并与原始资料区分** ✓（人类原话 ✓）
⚠ **登记要求（Lead 明令 ✓）**：
  · 文档与生成器 `reason` 都写明这是**本地规则**（术语里**没有**"萌化冒号"的独立条目 ✓）
  · 留一条注释：**「若人类日后改判为"触发" ⇒ 只改这一处」** ✓
  · 影响面对照（拍完后**必须**在判据里体现 ✓）：`723`（双方都萌化 ⇒ 回血算谁）· `732`（应对失败时还给不给）
```
