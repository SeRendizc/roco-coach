### A7 刷新天分没效果

- **原话**：「刷新天分没效果，刷新性格没试过但也要检查下」
- **截图**：`shots/03-detail-水泡壳-刷新天分.webp`（二级页有「刷新天分（还剩 3 次）」）
- **复现**：`box.html?pet=own-XXXX` → 点「刷新天分」→ 看「性格与资质」那一栏
- **我查到的事实（这条最硬，而且是我的判据设计缺陷）**：
  - 「刷新天分」的处理器在 `src/client/box.js:1029-1044`：
    它调 `refreshIndividual('talent', …)`（**写本机记录** `roco.box.individuals.v1`），
    然后 `renderPetPage()`。
  - 而页面上「性格与资质」那一栏（`#pet-traits`）读的是 **`state.petData`**，
    也就是 `?detail=` 的**服务端回执**（`box.js:519-536`）——
    服务端那份是按 `individual_id` **确定性掷出来**的，刷新本机记录**不会改变它**。
  - ⇒ **屏幕上那两个数字不可能变**。真正变的只有按钮上的「还剩 N 次」和下面那行小字。
  - ⚠ 而且状态行还写着 **「结果就在这一页上」**（`box.js:1042-1043`）——**这句话是假的**。
  - 顺带：**同一只精灵的资质存在两份互不相干的来源**（服务端回执一份、本机记录一份），
    这本身就是个设计问题。
- **我的判据为什么没抓到**：验收 28 号（「刷新→回滚→重刷」）量的是
  `localStorage` 里的 `talent_boosts` / `refreshes` 计数与那行小字，
  **没有断言屏幕上「资质」的数值发生了变化** ⇒ **判据量的是状态，不是屏幕**。
  这是我这一轮最该记住的一条教训（见 §B4）。
- **待裁决**：
  1. 「刷新」到底应该改**哪一份**数据？（服务端那份是确定性的、页面读它；
     本机那份是掷点、只有本机知道。）两者必须合成一份，否则这个按钮永远是假的。
  2. 「结果就在这一页上」这句假话要不要先删掉？
  3. 刷新性格要按同一口径一起修（人类说"没试过但也要检查"）—— 现在它走的是**同一条**代码路径，
     所以**有同一个 bug**。

### A8 使用技能后立绘消失（人类 2026-09-28 实测）

- **原话**：「没事我已经看到了，但是我刚刚使用光刃后立绘就消失了」
- **截图**：无（人类口述；复现路径清楚）
- **复现**：进入 PVE 对战 → 用任意技能（实测「光刃」）→ 该侧立绘消失
- **我查到的事实（机制已完全定位）**：
  1. 战斗页出手时调 `b3SwapVariant(cardSel, 'action', 900)`（`src/client/roco.js`），
     它原来会**真的把 `<img>` 换成正则要求 `v=action` 的那张图**；
  2. 而**抓包立绘只有一张静态图，没有动作态** ⇒ 动作 URL 404；
  3. 渲染那一侧注册的 `img.onerror` 原来是 **`img.remove()`** ⇒ 元素被删；
  4. 900ms 后 `b3SwapVariant` 的 `setTimeout` 想换回 `default`，**但那个 `<img>` 已经不在 DOM 里了**
     ⇒ 立绘**永久消失**（直到下一次 `renderB3Sprites()` 重建）。
  - ⚠ 触发它的是**本轮新加的抓包立绘**：在此之前 `pet_000004` 在 `/api/roco/sprite` 就是 404，
    战斗页本来就画不出图（`data-b3-sprite="none"`），所以"消失"这件事看不出来。
- **人类当场给的裁决**：「**舍弃动作立绘、保留动效**」
- **已经按裁决改完**（`src/client/roco.js`，三处）：
  1. `renderB3Sprites()` **永远只要 `default`** 那一张；
  2. `b3SwapVariant()` **只写标记、不碰 `img.src`** ——
     `data-b3-variant=action` 这个**线索**保留（战斗反馈验收把它与 `.b3-attack` 并列为
     "出手方线索"，是**或**关系，另外两条都还在），出手的"谁先动"由动效表达；
  3. `img.onerror` **不再 `img.remove()`**，只标记 `data-b3-sprite="none"`
     （真没图仍然留空、不画占位，但不再因为一次瞬时错误把立绘永久抹掉）。
- **待裁决**：无（人类已裁决）。**要验的话**：`node scripts/roco/browser-battle-feedback-acceptance.mjs`。
