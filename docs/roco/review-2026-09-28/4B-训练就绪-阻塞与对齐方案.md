## 八、阶段 3 再收一道：**失败轨迹不许当正向目标**（单独关进 `contrast.jsonl`）

### 8.1 问题（Codex 纠偏的核心，我上一版**没有真正处理**）

候选里 **24 条**的 `reply` 是**失败句**（「这次没有查到可用的规则事实…」），
而它们的 `target` 是**模型当年做错的那一步**（例：「为什么这一手要防御？」被标 `stop`）。
**我却把它们和干净样本混在同一个 `messages` 里、目标都是正向的** ⇒
**训下去就是"把失败教成正确决策"**。

我上一版只是把它们**打了标记**（`reply_is_failure`），**没有阻止它们进训练分片** ——
标记不等于隔离。**这一版做了真隔离。**

### 8.2 修法：按**极性**分流

- `polarity: 'positive'`（回复不是失败句）⇒ 进 `train/valid/test.jsonl`；
- `polarity: 'negative'`（回复是失败句）⇒ **单独进 `contrast.jsonl`**，**一条都不许进训练分片**；
  只能用于**对比 / 拒答**用途，**且必须由人定怎么用**。

实测分流：

| 文件 | 条数 |
|---|---|
| `train.jsonl` | **42**（只有正向） |
| `valid.jsonl` | **10** |
| `test.jsonl` | **17** |
| **`contrast.jsonl`** | **24**（全是 negative，带 `reply_is_failure` 标记） |

⇒ 正向合计 **69**，负向 **24**，共 93（与候选数一致，**没有丢样本**）。

### 8.3 冻结判据（`tests/roco-sft-dataset-contract.test.js` 现 **11/11**）

新增一条，两头都钉：
1. **训练分片里一条 `negative` 都不许有**（混进去就是"把失败教成正确决策"）；
