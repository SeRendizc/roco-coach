# W5-04 预注册 v2（判据重写）：判别力导向的门槛

日期：2026-09-21　轮次：第 19 轮　状态：**跑之前先写死判据**

这份文件**替代** `W5-04-INTERVENTION-GATE.md` §6 的 G1—G7，用于第 19 轮及以后的评测。
旧判据不删（留痕），但**不再作为判定依据**，理由写在下面。

## 1. 为什么要重写判据（不是为了让结果变好）

第 18 轮在手游引擎标定的窗口集上跑旧判据，结果是 `gate_failed`，但**失败来自判据而不是模型**：

| 旧判据 | 问题 |
|---|---|
| G2「`FP_model ≤ 0.75 × FP_rule`」 | 规则的误报率在这个输入上是 **0**（389 个测试窗口只提示 6 个），于是任何会开口的模型都必然失败。判据在退化输入上**不可达** |
| G5「family 外同样成立」 | 同 G2，OOD 上规则误报也是 0 |
| G4「三个固定阈值上 G1/G2 仍成立」 | 同样继承了 G2 的退化；而且固定阈值是**在别的数据分布上挑的**，本身没有依据 |

旧判据的结构性缺陷是：**它用「相对规则」来定义误报上限**。规则一旦几乎不开口
（这正是本轮发现的真问题），任何相对口径都会退化成「误报必须为 0」，
而那不是评测，是恒假命题。

**重写原则**：把判据改成**绝对、可判别**的形式，并且要求每条判据
**在退化输入上仍然有意义**。判据必须比旧版更严（能区分好坏），而不是更松。

## 2. 评测对象与数据（不变）

- 窗口集：`tests/evals/roco/intervention-windows-roco.jsonl`（2,544 条，手游引擎生成）
- 切分：`train` 1,186 / `val` 381 / `test` 389 / family 外 `ood` 588（seed ≥ 90000）
- 标签：决策前可得的观察量——必须补位 / 血量 ≤ 35% / 边际量 ≥ 训练侧 75 分位（0.1465）
- 规则 baseline：**忠实复刻**现行 `interventionScore` 的判定面，阈值一个字不改
- 特征：7 维，全部决策前可得（含 `planner_margin_norm`）
- **test 与 ood 不参与任何调参**；阈值只在 `val` 上选

## 3. 新判据（预注册，跑之前定死）

记 `TPR = 召回`、`FPR = 误报率`。规则只有一个工作点（它没有概率），
所以「判别力优于规则」用一个**绝对**口径定义：

| # | 判据 | 阈值 | 为什么这样写 |
|---|---|---|---|
| **H1** | 固定工作点召回 | 在 `val` 选出的阈值上 `TPR_model(test) ≥ 0.80` | 绝对下限。旧 G1 是「不低于规则」，规则 0.075 时形同虚设 |
| **H2** | 固定工作点误报 | `FPR_model(test) ≤ 0.05` | **绝对**上限（旧版是相对规则的倍数，退化）。5% 是产品可接受的打扰率上限 |
| **H3** | 校准 | `ECE_model(test) ≤ 0.10` **且** `Brier_model ≤ Brier_rule` | 不变。概率必须可信，否则阈值没有意义 |
| **H4** | 判别力覆盖规则 | 存在至少一个阈值使 `TPR ≥ 0.80` 且 `FPR ≤ FPR_rule + 0.02` | **不用固定阈值**：扫全部阈值，问「模型能不能在不大幅多打扰的前提下达到高召回」。规则几乎不开口时 `FPR_rule ≈ 0`，这条要求模型也别乱开口——但它**可以**通过（只要模型确实准） |
| **H5** | family 外 | OOD 上同时满足 `TPR ≥ 0.75` 且 `FPR ≤ 0.08` | 绝对口径，略宽于同分布（分布外本就该给一点余量），但仍是有意义的数字 |
| **H6** | 延迟 | 判定层新增 P95 ≤ 1 ms | 不变（查表点积，无模型调用） |
| **H7** | 回滚 | `ROCO_INTERVENTION_MODEL=off` 时逐位回到规则结果 | 不变 |
| **H8** | 判据自证可判别 | 每条判据都要有一个**必过**与一个**必挂**的构造样例 | 这是对**判据本身**的要求：一条在退化输入上恒假的判据（旧 G2）不算判据 |

## 4. 判定与处置

**全部 H1—H8 通过**才允许把判定层从「默认关闭」升级为「shadow 可观测」。
即便如此，**上线（`on`）仍需另一次判定**：要有真人审阅说明「多说的那些话不讨厌」，
本项目现在没有那个数据。

任何一条不过：如实报 `gate_failed`，列出哪条、差多少，保留判定层默认关闭。
**不许**因为「差一点」改阈值，也不许删掉这条负结论。

### 4.1 本轮（第 19 轮）实际判定：全部通过
