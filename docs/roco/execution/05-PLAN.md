## 按顺序执行

| 步骤 | 操作 | 必须留下的结果 |
|---|---|---|
| 05.1 | 冻结真实问句：现在怎么办、该换谁、有啥可以改进、这招能不能用；分别在局中/局外/局末检查意图，不靠单个关键词或有无 history 判断。 | 问句—阶段—路由—工具表。 |
| 05.2 | 把 04 结果转成首选、理由、主要风险和必要备选；每条动作绑定局面版本与 legalActionId，引用必须支持推论。 | 建议结构与证据映射。 |

| 05.4 | 真实页面验证查看不行动，采用建议只触发一次合法动作；切局、换人、玩家先行动后迟到回答不能采用。 | 点击前后状态、事件计数、取消原因。 |
| 05.5 | 主动提示去重并尊重关闭偏好；不挤正文、遮挡技能、抢焦点。桌面和窄屏检查长回答、滚动和输入区。 | 两视口截图与偏好/去重验证。 |
| 05.6 | 记录从事件到首条有效建议的时延，分本地/云端/回退；按总计划建议目标优化，但不牺牲事实与合法性。 | 原始时间点、样本与 p95；达不到时说明瓶颈。 |
