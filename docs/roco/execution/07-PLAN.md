## 按顺序执行

| 步骤 | 操作 | 必须留下的结果 |
|---|---|---|
| 07.1 | 把复盘与问答关联到少量明确知识点，如先手、能量、换人接应与未知配招风险；保留原始证据，不建立不可解释的总水平分。 | 知识点与证据结构。 |
| 07.2 | 问答先直接回答，再用当前队伍/刚才一手解释；允许追问依据，练习可跳过，不强迫先答题。 | 真实问答任务链。 |
| 07.3 | 生成同知识点但改变精灵、数值或对手情景的变式；用引擎核对答案与合理替代，不复制原局面答案。 | 变式夹具与规则验证。 |
| 07.4 | 记录未知、提示下成功、独立成功、跨局重复成功；区别主动提示、玩家求助与完全独立，不把赢局或采纳等同掌握。 | 掌握状态转换与来源事件。 |
