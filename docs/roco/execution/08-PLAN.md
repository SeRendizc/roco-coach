## 按顺序执行

| 步骤 | 操作 | 必须留下的结果 |
|---|---|---|
| 08.1 | 读取玩家本命宠、已有队伍、实际资源与目标；缺影响结论的输入才询问。未见对方阵容前只谈常见威胁，不能针对隐藏对手配队。 | 目标/约束结构与缺信息分支。 |
| 08.2 | 给一套有打法的 6×4：首发、核心配合、换人接应、技能职责与主要弱点。不能只列属性计数或每宠百科。 | 可实际进入对局的完整队伍与打法说明。 |
| 08.3 | 提供一个必要调整并比较前后收益/代价；保留用户锁定成员，允许不调整。培养建议用同一个体投影比较具体先手/承伤/伤害阈值。 | 前后个体/队伍快照与真实计算。 |
| 08.4 | 应用前预览，应用后可撤销；确认技能合法、个体 ID 独立、保存失败可见。禁止修改或清理用户既有数据，使用专用测试 profile。 | 预览/应用/撤销及多实例隔离证据。 |
| 08.5 | 从复盘进入相关练习或培养比较，再打一局检查目标是否得到改善；不能把面板数增长自动解释为战术改善。 | 跨页完整链与目标验证。 |

每做完一步更新 STATE.json 的 step 和 next_action。测试失败先定位本步最小原因；不要跳到下一步靠更多功能掩盖失败。
