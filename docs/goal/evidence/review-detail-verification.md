# 战斗复盘「具体细节」验证（2026-10-17 晚）

**结论：能看到具体细节** —— 复盘文本/依据里已带**回合号、伤害数值、出手者、合法替代、资源账**，
且这些细节由页面同一个 `rocoMatchReview()` 产出（页面只负责渲染，不另拼）。

## 实测方式

用 8910 真服务打一局（seed 20261017、greedy_damage，13 回合 loss、70 条事件），
逐回合收集 `view.legal` 作为 `legalByTurn`，再调用页面同源
`src/coach/roco-experience.js::rocoMatchReview()`（**本地、不调模型、0 付费**）。

## 实测产出（节选）

- **转折点**：`turning_point = {turn: 6, rule: 'first-faint'}`，候选规则还有 `damage-lead-flip`。
- **正文具体到回合/数值**：
  > 第 6 回合 对方第 1 位 倒下，这是全场第一次减员。……第 8 回合当时的合法动作里还有「换上第2位」这一项，当时你做的是「使用回复药」。……第 2 回合已经吃过一次属性克制的伤害（约 130 点，倍率 2），到第 8 回合倒下之间没有换过人——这一课要改的是「把这一只换下去」。
- **关键片段**：第 11 回合对方「彗星」约 241 点；我方该回合共挨约 241 点。
- **资源账**：主动换人 0 次 / 被动补位 2 次；道具 1 次（第 8 回合回复药 +45）；回合末能量最低 1 点（第 1/9/11 回合）；减伤/应对 3 次（第 1/4/7 回合）。
- **合法替代（U10）**：`alternative = {anchor_turn: 8, label: '换上第2位', menu: ['换上第2位','换上第3位'], reason: …}`——
  “当时还能选什么”直接摆在依据里，并注明“只说当时有这一项可选，不代表换了就赢”。
- **深度覆盖**：`covers_whole_match=true`，`depth.facts=6`，`mistake_available=true`，候选课题 3 条。

## 边界

- 这次验证的是**复盘构建函数**（页面渲染它的 `review.text/evidence/depth`），不是浏览器逐屏点击；
  Chrome headless 在当前 sandbox 会挂起，UI 层仍以之前 200 + 同源构建函数为准。
- 若把 `legalByTurn` 去掉，复盘会如实写“查不到当时合法表”，不编替代——这一条由现有单测钉着。
