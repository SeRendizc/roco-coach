### 一个重要的坑（容易把 540 读错）

540 是**图鉴侧行数**（"图鉴有 540 行采用抓包六维"），
它同时等于"抓包 547 个 id 里有 540 个 distinct id 出现在图鉴里"——

## ③ 574 是怎么算出来的

### 结论

**`574 = 622 − 48`**，两个减数**都不是** 547 或 540。
- `622` = `data/roco/game-data-pack/v2/pack.json` 里 `group === 'pet'` 的实体数（每个实体唯一 id）；
- `48` = 冻结 `normalized/` 目录里**有 `learnsets.json` 条目**的物种数（主 learnsets.json 12 条 baseline + `layer-playable-48/learnsets.json` 36 条 overlay）；
- `574` = 上面两者的差，且**实测恰好**都落在同一个 reason 上（其余 reason 计数都是 0）。

574 与 547 / 540 的关系是"**同源不同轴**"：它们的候选宇宙都是同一个 622（pack），
但 547/540 数的是"抓包覆盖了多少"，574 数的是"有多少只因缺冻结学招表而不能配技能"。
唯一交集：574 那批里包含 25 条由抓包 4xxx 段生成的 pack 实体（钻石蜗 6 条形态就是 `pet_000580-585`）。
