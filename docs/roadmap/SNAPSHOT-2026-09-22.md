## 八、第 150–154 轮：战斗页真机问题收口（人类实测驱动的缺陷）

### A. 「战斗完全推进不了」——两条**真**根因（都已修）

1. **陈旧动作信号**：技能格/换宠行的 `data-b3-action` / `data-b3-slot-legal`
   *只在有动作时写、从不清除* → 引擎这一手没给技能时，格子仍显示「可点」，点下去什么都不发生。
   修法：每次渲染**先清后写**；点击按**身份**（`kind` + `skill_id` / `target`）在当前
   `view.legal` 里重新解析，下标只作兜底。
2. **整局静默假死**（子代理真机量到，5 次中 2 次、第 6/7 回合）：引擎**拒绝这一步**时
   `/api/roco/battle/advance` 回 `{ok:false,error}` 但**仍是 HTTP 200**；页面 `api()` 只在非 2xx 抛，
   `applyResult()` 又无条件 `state.view = data.view` → view 被清 **null** → 页眉「未开局」、战报消失、
   `battleId` 仍在 → **一个字都不提示的假死**。
   修法（客户端已落地）：`applyResult()` 在 `ok===false` 或没有 `view` 时**保留上一帧局面** +
   把原因写进状态行「这一步没被接受：<error>（局面保持在上一手）」。
   **待办（服务端）**：把 `ok:false` 显式映射成非 2xx / 带 `error_type`。

### B. 对手池（人类：别选不可用的）

- 旧实现把玩家的**实例 id**（`own-XXXX`）当物种去比 → 与对手池（物种）**根本不相交** →
  从 574 全量池里抽，可能抽到我没有/不能上场的物种。
- 新实现：先从**我持有的可用物种**（`owned-pets.json` 的 species ∩ 有按需 build 的物种）里选、
  去掉我这一队；不够才退回全量池，来源记 `enemy_source`。
  实测**开局正常**（turn 1 / 11 条合法动作 / autoTurn 1→2），对手换成可用池物种（朔夜伊芙）。

### C. RC-401 实现范式（已核实，供下一批照做）
