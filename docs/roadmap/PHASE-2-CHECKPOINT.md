### 3.5 兜底把**未过事实守卫的模型正文**端给玩家（Lead 抓到并修，`af1406f`）

全量单测里 `tests/evals/agent.test.js` 有一条红。最小复现：

```
provider: local-fallback          ← 标着"本机兜底"
text:     造成99999伤害，必胜      ← 却是模型那段**没过事实守卫**的原文
```

**根因**（`src/coach/client.js` 两支都有）：`text: data.localText ?? data.text` ——
`localText` 缺席时就退回 `data.text`，而**那正是刚被守卫拦下来的那段**。
⇒ 守卫拦下的东西又从兜底漏出去，回执还标着 `local-fallback`。
**这是 P0-01 要修的同一类**：「A 路失败就退到一处没被守卫覆盖的内容」。

**修法**：`deterministicText()` —— 有 `localText` 用它 / 没有就**真跑本机那一条** /
连它都拿不到就交**一句如实的话**，**绝不放模型原文**；另加 `deterministicFrom` 如实标注来源。
验证：**我用自己的复现**（`含 99999: false`、`deterministicFrom: local-run`）+ 相关族 **125/125**。

**横向审计**（Lead 做的）：`grep -rnE "\?\?\s*(data|d)\.text\b|localText\s*\?\?" src/` ⇒ 只剩注释留档；
`text: data.text` 之类**一处不剩** ⇒ 这个 bug 类**只此一处**。
