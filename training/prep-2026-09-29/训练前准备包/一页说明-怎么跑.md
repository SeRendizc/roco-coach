## ⚠ 附录二：**数据一变，`READY.json` 就作废**（务必重填）

`READY.json` 里记了**三份数据的 sha256 与行数**（`data` 段 ✓）—— 这是**故意的**：
```
⇒ 只要 `train/valid/test.jsonl` 有任何一行变了，**READY 里的指纹就不再对应** ✗
⇒ ⇒ **必须重跑一次填指纹**（不是"改个数字" ✗ —— 要用真文件的 sha256 ✓）
```
**重填命令**（一条，我写的 ✓）：
```bash
cd /Users/serendizc/Developer/roco-coach
python3 - <<'EOF'
import json, hashlib, os, datetime
D='training/prep-2026-09-29/router-v9'; P='training/prep-2026-09-29/训练前准备包/READY.json'
d=json.load(open(P))
for s in ('train','valid','test'):
    p=os.path.join(D,s+'.jsonl'); rows=[l for l in open(p) if l.strip()]
    d['data'][s]={'bytes':os.path.getsize(p),'lines':len(rows),
                  'sha256_16':hashlib.sha256(open(p,'rb').read()).hexdigest()[:16]}
d['at']=datetime.datetime.now().isoformat(timespec='seconds')
json.dump(d, open(P,'w'), ensure_ascii=False, indent=2)
print('已重填：', {k:{'lines':v['lines'],'sha':v['sha256_16']} for k,v in d['data'].items()})
EOF
```
⚠ **注意**：`READY.json` 的**判据真假（`checks`）不因为重填而变** ✓ —— 指纹只是"这份数据是哪一份"的凭据 ✓
⇒ 若数据的**覆盖面/审核**变了（例如从 7 类工具扩到 12 类 ✓）⇒ **`data_reviewed` 的依据也要跟着更新** ✓（我或审核者来填 ✓）
